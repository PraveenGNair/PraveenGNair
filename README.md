# praveengnair
Personal Profile website https://praveeng-nair.web.app

To deploy the application, follow these steps:
1. **Clone the Repository**: Clone the repository to your local machine.
2. **Install firebase dependencies**: Run `npm install -g firebase-tools` to install the required dependencies.
3. **Login to Firebase**: Run `firebase login`.
4. **Deploy to Firebase**: Run `firebase deploy --only hosting -m "message" --project praveeng-nair` to deploy the application to Firebase Free Hosting.
